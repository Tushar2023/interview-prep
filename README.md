# interview-prep

Company-specific interview prep dashboard (static page, progress stored in Supabase behind auth — same account as [job-tracker](https://github.com/tushar2023/job-tracker)).

Live: https://tushar2023.github.io/interview-prep/

## What's in it

- `index.html` — the app. Companies → DSA / System design / LLD buckets, per-question status
  (1st attempt ✓ · 1st + hints · 2nd attempt ✓ · 2nd + hints), ★ must-revise, notes, filters,
  "All questions" view (sorted by how many target companies ask the same problem), revise queue.
- `data.js` — the question bank, generated by `tools/merge.py`:
  - LeetCode company tags from the [snehasishroy](https://github.com/snehasishroy/leetcode-companywise-interview-questions)
    snapshot (12 Jul 2026), ranked with a recency bias (30-day list weighted highest);
  - interview-experience research per company (`data/research/*.json`: process, rounds, reported
    DSA / design / LLD questions with sources);
  - LeetCode topic tags from [prathameshakole/leetcode-problems](https://github.com/prathameshakole/leetcode-problems);
  - `LC150` badge = problem is in LeetCode's Top Interview 150 study plan.
- Progress model: one row per user in `public.prep` (`data` jsonb, `rev` for optimistic concurrency),
  cached in `localStorage`, exported/imported as JSON from the ⋯ menu.

## Refreshing the question bank

```
python3 tools/rank_lc.py <leetcode-companywise-interview-questions dir> data/lc google uber stripe databricks airbnb atlassian microsoft amazon booking=bookingcom rubrik coinbase broadcom
python3 tools/merge.py data data.js
```

## Supabase

```sql
create table if not exists public.prep (
  user_id uuid primary key references auth.users(id) on delete cascade,
  data jsonb not null default '{}'::jsonb,
  rev integer not null default 0,
  updated_at timestamptz not null default now()
);
alter table public.prep enable row level security;
create policy "prep select own" on public.prep for select using (auth.uid() = user_id);
create policy "prep insert own" on public.prep for insert with check (auth.uid() = user_id);
create policy "prep update own" on public.prep for update using (auth.uid() = user_id) with check (auth.uid() = user_id);
```
